# Drone Mission Planner

Drone Mission Planner is a lightweight Python application for creating and managing simple drone flight routes.

Users can build missions by adding GPS waypoints, store them locally, and export them to JSON for later use.

## Features

- Create missions
- Add GPS waypoints
- Save locally
- Export JSON
- Route summary

## Run

```bash
python src/main.py
```

## Example

```
Mission: Forest Patrol

Waypoints:
1. 50.4501 30.5234
2. 50.4515 30.5262
3. 50.4540 30.5288

Mission exported.
```
